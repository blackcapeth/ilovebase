# ilovebase

A small test repository used for a first GitHub commit, themed around Base on Ethereum.

## What is here

The first commit added a `read.me` file. There is no application code, and there is no GitHub Pages site.

## How to use

Clone the repository:

```
git clone https://github.com/blackcapeth/ilovebase.git
cd ilovebase
```

You can use this repo as a starting point for Base experiments, or keep it as a record of that first commit.
